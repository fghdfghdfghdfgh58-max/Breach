# Arena FPS (standalone)

Anyone with the link can play. No Claude account needed.

## Run locally
    npm install
    npm start
Open http://localhost:3000. Friends on your Wi-Fi can use http://YOUR-LOCAL-IP:3000.

## Put it online (free options)
Upload this folder to a GitHub repo, then on Render.com choose New > Web Service:
- Build command: npm install
- Start command: npm start
Render gives you a public https link. Send that link to friends. (Railway, Glitch, Replit and Fly.io also work.)
Free tiers sleep when idle, so the first load can take ~30 seconds.
